# Skeptic's Guide to LLM Engineering [WIP]

Build LLM applications from **Chat Interface** → **RAG** → **MPC protocols** → **Coding Agents** → **Agent Loops** in standalone Python scripts with **zero frameworks**.

# Introduction

This repository is an exploratory project built from the point of view of a traditional software developer, who is quite exhausted this AI hype. I do not buy the notion that AI can make me a 10x developer. It seems every day a new technique pops up claiming it will "skyrocket your productivity". **I will build each concept from first principles, using minimal code to find what actually works, and what is just snake oil.**

> Apparent people are done coding and are now writing "loops".

## Python Dependencies

Lang-chain/-graph/-Spaghetti ! is one the worst framework. It is a mess of unstable implementations spread across a nightmare of breaking versions. Upgrading dependencies due a criticality can be injurious to mental health.

So, we are going to use simple stuff.

- [Ollama](https://github.com/ollama/ollama-python): Probably the lightest framework, Extremely easy to login and there are some free-tier cloud models.
- [Marimo Notebook](https://github.com/marimo-team/marimo): A modern, reactive replacement for Jupyter that is actually reproducible and far easier on the eyes.
